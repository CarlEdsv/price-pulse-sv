# PricePulse El Salvador (PISTO) 📊💎

PricePulse El Salvador es una plataforma analítica y de crowdsourcing concebida para monitorear, predecir e informar sobre los precios del mercado nacional de bienes y servicios.

## Características Principales

*   **Dashboard de Mercados (Canasta Básica, Servicios, Insumos):** Seguimiento en tiempo real de los precios promedio a lo largo de El Salvador.
*   **Crowdsourcing Integrado:** Los usuarios pueden escanear facturas e ingresar datos manuales a cambio de recompensas y beneficios Premium (Gamificación).
*   **Suscripción Premium (Simulación):** 
    * Predicción de mercados basada en IA.
    * Ahorros exclusivos.
    * Cálculo de costo y tiempo de movilidad desde tu ubicación actual a la tienda vs el costo en línea.
*   **Hub Financiero y B2B:** Inteligencia de negocios para comercios con analíticas anónimas de usuarios (DaaS) y opciones de inversión para proteger capital a través del sector nacional o internacional (Hapi, XTB).

## Stack Tecnológico 
- Vanilla JS (Vite)
- CSS (Diseño responsivo Glassmorphism, Premium Dark UI)
- HTML5

## Desarrollo Local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/TU-USUARIO/price-pulse-sv.git
   ```
2. Instala las dependencias y ejecuta el servidor local de desarrollo:
   ```bash
   npm install
   npm run dev
   ```
